# Estrella y el Castillo de los Números

Juego de matemáticas para una Amazon Fire 7 (2022). Godot 4.7.2, en dos dimensiones, sin internet.

El diseño vive en el wiki del repositorio y, en paralelo, en `docs/`. Los encargos de cada experto están en `agentes/`. Las restricciones que no se pueden contradecir están en `BRIEF.md`.

- Plan: `docs/PLAN.md`
- Documento único: `docs/GDD.md`
- Capítulos: `docs/expertos/`
- Specs: `docs/specs/`
- Assets y datos: `assets/`, `data/`

No hay datos de una niña real en este repositorio.
