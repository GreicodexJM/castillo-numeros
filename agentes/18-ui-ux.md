# Agente: UI y UX

Lees `docs/GDD.md` y `BRIEF.md`. Español de España. Sin atribución a IA.

Entrega `docs/specs/ui-ux.md` y, si puedes, SVG de marco y botones en `assets/ui/`.

Pantalla útil 1024×552, botones de unos 96 px, una idea por pantalla, texto siempre visible además de la voz. Flujos: mapa, sala, fallo, ayuda, cierre, rincón del padre con PIN. Nada de marcador, vidas, estrellas vacías ni cronómetro. Letra grande. El color no es la única pista.
